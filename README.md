# 台股籌碼分析 Agent

## 專案目標

每週彙整台股三大法人籌碼變化,產出排行榜,並支援自然語言查詢。

> **本專案不是投資建議工具,是資料彙整工具。** 排行榜僅呈現公開資料的統計結果,不構成任何買賣建議。

## 核心輸出:16 張週排行榜,每張 20 名

| 類型 | 組合 | 張數 |
| --- | --- | --- |
| 買賣超張數榜 | 外資、投信、自營商 × 增加 / 減少 × 上市 / 上櫃 | 12 |
| 外資持股比率變化榜 | 增加 / 減少 × 上市 / 上櫃 | 4 |

- 每一列都附該週漲跌幅。
- **投信與自營商不做持股比率榜**:官方沒有提供這兩類法人的持股比率資料,無從計算。

## 過濾規則

- **排除 ETF / ETN / 受益憑證**:以證交所的證券類別欄位判定,不用代號前綴推測。上櫃股票對應的類別欄位來源:待補。
- **最低成交量門檻**(寫成設定檔參數,不寫死在程式裡;設定檔檔名與格式:待補):
  - 上市:週均日成交量 >= 1000 張
  - 上櫃:週均日成交量 >= 200 張
  - 此為**初始值**,待實際跑過後調整。
- **除權息標註**:除權息當週的個股加上旗標,避免把除權息造成的股價下跌誤讀為真實跌勢。

## 資料來源

| 資料 | 來源 | 用途 | 網址 |
| --- | --- | --- | --- |
| 上市法人買賣超 | 證交所 T86 三大法人買賣超日報 | 上市的外資 / 投信 / 自營商買賣超張數榜 | 待補 |
| 上櫃法人買賣超 | 櫃買中心 三大法人買賣明細資訊 | 上櫃的外資 / 投信 / 自營商買賣超張數榜 | 待補 |
| 上市外資持股 | 證交所 外資及陸資投資持股統計 | 上市外資持股比率變化榜 | 待補 |
| 上櫃外資持股 | 櫃買中心 僑外資及陸資持股比例排行表 | 上櫃外資持股比率變化榜 | 待補 |
| 股價與漲跌幅 | 證交所 / 櫃買中心 每日收盤行情 | 每週漲跌幅;成交量門檻所需的成交量(欄位待確認) | 待補 |
| 證券類別 | 證交所證券類別欄位(上櫃對應來源待補) | 排除 ETF / ETN / 受益憑證 | 待補 |
| 除權息資訊 | 待補 | 除權息當週旗標 | 待補 |

**注意:外資持股比率變化 ≠ 外資買賣超。** 外資持股數除了集中市場的買賣,還受借券、DR、CB 轉換、增減資、ETF 申購買回等非集中市場因素影響,所以持股比率的變化不能直接當成買賣超來解讀。這也是兩種榜單分開做的原因。

## 系統架構

```mermaid
flowchart LR
    A["資料層<br/>每日排程抓取<br/>寫入本地資料庫"] --> B["計算層<br/>純 Python 計算排名<br/>確定性、可測試"]
    B --> C["Agent 層<br/>LLM:意圖判斷、呼叫 tool、轉成自然語言"]
```

1. **資料層**:每日排程抓取上述資料來源,寫入本地資料庫。
2. **計算層**:純 Python 計算排名。結果是確定性的、可以寫單元測試,**不經過 LLM**。
3. **Agent 層**:LLM 只負責三件事——判斷使用者意圖、把計算層當 tool 呼叫、把結果轉成自然語言。

**排名計算不交給 LLM,因為 LLM 做數值排序不可靠。**

## 互動設計

- 單次查詢只回**一張榜**。
- 完整 16 張榜另外輸出成檔案(檔案格式:待補)。
